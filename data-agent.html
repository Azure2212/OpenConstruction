AEC Dataset · Capability Framework & Benchmark

A deterministic reference baseline for an AEC data agent. It reasons over dataset metadata only — never downloads files — to discover, understand, evaluate, compare and select datasets, and abstains when nothing fits. Every step below is an inspectable capability (C1–C5), scored by a no-LLM-judge benchmark. The conversational LLM agent layer plugs in on top of these same capabilities — it is not this layer.

Every panel is real deterministic-engine output. Where the engine has no datum (e.g. BIM / point-cloud content profiling) the canvas says so — it never fabricates a number.
